# Редактор графа УДС (OSM)

Веб-редактор уличной сети: открывает `.osm`, показывает в 2D поверх карты, даёт править узлы, дороги,
направления, полосы, светофоры, мосты, подсвечивает ошибки и сохраняет `.osm`, пригодный для SUMO / MATSim / Webots.

Без бэкенда: всё работает в браузере (Vite + React + TypeScript, Canvas 2D).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

Без установки Node (Docker):

```bash
docker compose up --build   # http://localhost:8080
```

Прочее:

```bash
npm test                              # тесты (парсер, undo/redo, валидатор, прогон через SUMO)
npm run build                         # продакшен-сборка в dist/
npm run check:sumo -- file.osm        # проверить файл через SUMO netconvert
npm run stats -- file.osm             # статистика транспортного графа и проблем
```

### Транспортный граф

`src/core/graph.ts` строит из документа направленный граф только для дорог машин. Узел графа — перекрёсток или
конец дороги, ребро — отрезок между ними (двусторонняя дорога = 2 ребра, `oneway` = 1; кольцо и магистраль
односторонние по умолчанию). Граф нужен валидатору, а также удобен для 3D и интерполяции Z вдоль цепочки рёбер.

```ts
const g = buildGraph(store.doc)          // или graphFor(store.doc, store.version) — с кэшем
const a = analyze(g)                     // a.main, a.traps, a.noEntry, a.detached
```

Для проверки в SUMO: `pip install eclipse-sumo` (в venv) или задайте `SUMO_HOME`. Тест `sumo.test.ts` пропускается, если SUMO не найден.

## Как пользоваться

- **Открыть** (Ctrl+O) или **Пример** — загрузить `.osm`.
- Колесо — масштаб, перетаскивание — сдвиг карты. Клик — выбрать дорогу (при приближении — узел).
- Выбранный узел можно перетащить мышью. Справа — атрибуты, шаблоны дорог, теги.
- **R** — развернуть дорогу, **Del** — удалить, **Ctrl+Z / Ctrl+Shift+Z** — отмена/возврат, **Esc** — снять выделение.
- Вкладка **Проблемы** — найденные ошибки; клик по строке переводит карту к месту.
- **Сохранить** (Ctrl+S) — проверка + скачивание `<имя>.edited.osm`. Опции экспорта: только дороги, + пешеходные, метаданные.

## Устройство

```
src/core/types.ts      КОНТРАКТ: OsmNode / OsmWay / OsmRelation / OsmDocument
src/core/parse.ts      .osm (XML) → OsmDocument
src/core/serialize.ts  OsmDocument → .osm; экспорт «только дороги»
src/core/store.ts      хранилище + транзакции + undo/redo (store.commit)
src/core/ops.ts        операции редактирования (moveNode, reverseWay, splitWayAt, ...)
src/core/roads.ts      классы дорог, стили, направление (oneway)
src/core/geo.ts        Web Mercator, расстояния
src/core/graph.ts      транспортный граф: buildGraph, SCC (Тарьян), analyze (ловушки / нет въезда / отдельные куски)
src/validate/index.ts  валидатор: массив CHECKS, каждая проверка (doc) => Issue[]
src/ui/MapView.tsx     Canvas-карта: отрисовка, pan/zoom, выбор, перетаскивание узла
src/ui/tiles.ts        подложка (растровые тайлы)
src/ui/AttributePanel.tsx  панель атрибутов и шаблоны
src/ui/IssuesPanel.tsx     список проблем
src/App.tsx            тулбар, горячие клавиши, сохранение
```

Правило правок: любая правка — через `store.commit('название', tx => { tx.setNode(...) })`.
Транзакция сама запоминает «было/стало», поэтому undo/redo работает без дополнительного кода.
Новые объекты получают отрицательные id (`tx.newId()`).

В режиме разработки store доступен в консоли браузера: `__store.doc.ways`, `__store.undo()`.

## Распределение ролей (6 человек)

| # | Роль | Файлы | Что делать |
|---|---|---|---|
| 1 | Ядро данных | `src/core/*` | Сохранение без потерь, split/merge ways с relations, новые операции, тесты |
| 2 | 2D-карта | `src/ui/MapView.tsx` | Скорость отрисовки, пространственный индекс (rbush), выбор нескольких объектов |
| 3 | Инструменты | `src/ui/MapView.tsx`, `ops.ts` | Рисование дороги, добавление узла на дорогу, соединение, разрез, hotkeys |
| 4 | Панель атрибутов | `src/ui/AttributePanel.tsx` | Полосы, `turn:lanes`, светофоры, мосты (`bridge`+`layer`), шаблоны, автозаполнение |
| 5 | Валидатор | `src/validate/*`, новый `src/core/graph.ts` | Транспортный граф, сильная связность с oneway, тупики, пересечения без узла |
| 6 | Подложка, Docker, 3D | `src/ui/tiles.ts`, `Dockerfile` | Своя подложка/картинка, образ, 3D (three.js) и плавный Z (`ele`) |

Чтобы не ломать друг другу файлы: свой модуль — свои файлы, контракт `src/core/types.ts` менять только по договорённости.

## Что отдаём симуляторам

Экспорт по умолчанию — только дороги для машин + запреты поворотов, у которых остались все участники.
Здания и маршруты общественного транспорта отбрасываются (их обрезка по рамке даёт кучу предупреждений в SUMO).
Служебные атрибуты (`user`, `changeset`, ...) по умолчанию не пишутся.
Проверено: SUMO `netconvert` проходит на исходном файле и на файле после правок и экспорта.

## Подложка и условия использования

По умолчанию подложка — тайлы OpenStreetMap (годится для демо; для нагрузки нужен свой тайл-сервер).
Любой другой источник — шаблон URL в поле рядом с чекбоксом «подложка».
Яндекс/Google/2ГИС: условия использования ограничивают кэширование и сохранение тайлов,
подключать их надо со своим ключом через официальное API.
